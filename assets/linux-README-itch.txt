Prospero for Linux
==================

Run ./prospero. Nothing needs installing: it needs glibc 2.28 or later
(RHEL 8 and its rebuilds such as Rocky and AlmaLinux, Debian 10,
Ubuntu 18.10, Fedora 29, or later), and it shows its window through
Wayland or X11, with OpenGL, which a desktop has.

For a menu entry, copy prospero.desktop to ~/.local/share/applications,
and set its Exec to this prospero's full path, and its Icon to
prospero.png's.

Desktop control is built in, and so are the engines it deploys on other
machines, for Linux, Windows and macOS.
